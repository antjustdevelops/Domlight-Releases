Install on a Windows PC:
1. Download Domlight_Setup_v150_STABLE_CANONICAL.zip from the v150-stable GitHub Release.
2. Extract the ZIP completely.
3. Run INSTALL_DOMLIGHT_v150_STABLE.cmd.
4. Existing Documents\Domlight\data is preserved; never delete it manually.
5. On a new PC, portal/Gmail authorization may be required again.

IMPORTANT RELEASE POLICY:
- v150 STABLE is the canonical accepted setup release.
- v149 packages/installers are WITHDRAWN and must not be installed.
- The old root Domlight_Setup.zip is a legacy v96 artifact and is NOT the current installer.
- latest.json remains intentionally pinned to v111 because the existing in-app updater is file-by-file. It must not be pointed at v150 until a separately tested package-updater mechanism is accepted.
